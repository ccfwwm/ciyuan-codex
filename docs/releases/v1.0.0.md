> 登录账户、选择模型，一键接入词元互联并启动官方 Codex。
> Sign in, choose a model, and connect official Codex to Ciyuan in one click.

## ✨ 亮点 · Highlights

- **一账户，三节点**：默认 XYZ 直连，可切换 CN 与香港节点，自动验证会话；失败保留原节点。
  One account across three verified routes, with XYZ direct by default and safe switching to CN or Hong Kong.
- **原生账户中心**：登录、注册验证码、记住登录、密码找回、USD 余额、低余额提醒、充值二维码和分页订单。
  Native sign-in, email registration, remembered sessions, password reset, USD balance, payment QR codes and paginated orders.
- **一键模型连接**：按可用分组创建或复用专用 Key；首版五个模型经过 Responses 流式输出和工具调用验证。
  Dedicated group keys and five admitted models verified for Responses streaming and tool calls.
- **安全保存与恢复**：系统凭据库保管会话和 Key；Codex 直接启动也可读取。备份并合并配置，保留项目、MCP、权限和原登录文件。
  Sessions and keys stay in the OS vault, accessible to Codex through a credential helper. Recoverable configuration merges preserve projects, MCP and original login files.
- **独立品牌与更新**：默认 1100 × 720 工作台，浅色/深色主题；保留官方 Codex 安装、更新及皮肤，更新源改为本仓库 GitHub Releases。
  An independent 1100 × 720 workbench with light/dark themes, existing desktop management and skins, and updates from this repository's GitHub Releases.

## 🐛 修复 · Fixes

- **失败保护**：预检或模型验证失败不改 Codex 配置；检测外部修改时暂停覆盖，失败节点切换保留有效连接。
  Failed preflight/model validation leaves Codex configuration intact. External edits are preserved and failed route switches retain the previous connection.
- **支付状态**：订单自动刷新，支付完成后同步余额；服务器渠道、限额、币种和手续费为准。
  Pending orders refresh automatically and completed payments refresh balance, with server-provided billing settings.

## 📦 安装与升级 · Install & Upgrade

手动安装选择 EXE / DMG。已安装本项目的用户可在应用内检查更新；首次接入需要安装兼容版本的官方 Codex，应用自动预检。
Choose EXE / DMG for manual installation. Existing Ciyuan installations can check in-app. Compatible official Codex is required and checked before integration.

**系统签名**：Windows 首版无 Authenticode 发行证书；macOS 使用 ad hoc 签名，未进行 Apple 公证。系统可能提示未知发行者。Tauri 更新签名只认证字节，不代表系统发行者身份。
**System signing:** Windows installers are not Authenticode-signed. macOS uses ad hoc signing without notarization. OS warnings may appear; updater signatures authenticate bytes only.

**校验 / Verify:** Windows 用 Get-FileHash -Algorithm SHA256，macOS 用 shasum -a 256，对比本页 SHA256SUMS。

.app.tar.gz、.sig 和 latest.json 是自动更新工件，手动安装请选择安装包。
.app.tar.gz, .sig and latest.json are updater artifacts; choose installers for manual installation.

应用模型前的小型验证请求按平台正常计费。真实付款由用户在自己的支付工具验收。
Applying performs a small billed verification request. Real payments remain a manual acceptance step.
