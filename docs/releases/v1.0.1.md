> Fix AI Platform confirmation permissions to restore applying and launching Codex.

## ✨ 亮点 · Highlights

- **确认后继续**：应用并启动、应用配置、恢复配置和退出账户统一使用原生确认弹窗，取消后不执行操作。
  Apply and launch, apply configuration, restore configuration and sign out use native confirmations; cancelling leaves the operation unexecuted.

## 🐛 修复 · Fixes

- **启动被权限拦截**：修复点击“验证、应用并启动”时出现 `Command plugin:dialog|confirm not allowed by ACL` 的问题。
  Fix `Command plugin:dialog|confirm not allowed by ACL` when clicking “Verify, apply & launch”.

## 📦 安装与升级 · Install & Upgrade

已安装词元互联 Codex 的用户可在应用内检查更新；手动安装选择 EXE / DMG。更新源仅为本仓库 GitHub Releases。
Existing Ciyuan installations can check in-app. Choose EXE / DMG for manual installation. Updates use this repository's GitHub Releases.

| 平台 · Platform | 安装包 · Installer |
| --- | --- |
| Windows x64 | Ciyuan-Codex_1.0.1_windows-x64-setup.exe |
| Windows ARM64 | Ciyuan-Codex_1.0.1_windows-arm64-setup.exe |
| macOS Intel | Ciyuan-Codex_1.0.1_macos-x64.dmg |
| macOS Apple Silicon | Ciyuan-Codex_1.0.1_macos-arm64.dmg |

**系统签名 / System signing:** Windows 安装包无 Authenticode 签名；macOS 使用 ad hoc 签名，未进行 Apple 公证。系统可能提示未知发行者。Tauri 更新签名不代表系统发行者身份。
Windows installers are not Authenticode-signed. macOS uses ad hoc signing without notarization. OS warnings may appear; updater signatures authenticate bytes only.

**校验 / Verify:** Windows 使用 Get-FileHash，macOS 使用 shasum -a 256，对比本页 SHA256SUMS。

.app.tar.gz、.sig 和 latest.json 是自动更新工件，手动安装选择安装包。
.app.tar.gz, .sig and latest.json are updater artifacts; choose installers for manual installation.
